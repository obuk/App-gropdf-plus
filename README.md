# NAME

App::gropdf::plus - gropdf + OpenType/CFF

# SYNOPSIS

    use App::gropdf::plus;
    App::gropdf::plus->run

# DESCRIPTION

This module separates Type1 font from the GNU groff 1.24.0 PDF driver
gropdf (written by Deri James) and adds OpenType/CFF support.

Please note that this module is intended for use with plenv.
